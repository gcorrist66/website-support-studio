## WSS Preview Recipe (reusable — Codex builds from this without guessing)

Applies to all no-owned-site DBPR prospects. Teaser = above-the-fold only (logo + hero + headline + primary CTA + ONE trust signal). Full preview page lives behind the click.
### Fixed structure (every vertical)
1. Logo / company name (top-left).
2. Hero band (vertical-themed background, see profiles below).
3. Main headline = `<Service> in <City>` (e.g., "AC & Heating in Dade City").
4. Sub-headline = WSS offer line: "We build it. We host it. We maintain it. You run your business." (preview-page only, not teaser).
5. Primary CTA button = phone-first: `Call (xxx) xxx-xxxx`. Use a quote/schedule verb only when an email exists.
6. ONE trust signal = the DBPR license badge: `FL Licensed <LICENSE#>`. This is the only verifiable trust proof these no-site prospects have — no reviews, no testimonials, no fabricated claims.
### Trust-signal rule (no placeholder claims)
- Default trust = state license number from the tracker (real, verifiable).
- Optional second tier IF found by Doge: years in business, "Licensed & Insured," local city tag.
- Never invent reviews, ratings, awards, or project counts.
### Per-vertical design profiles
| Profile | Hero palette / motif | Headline pattern | CTA verb | License prefix seen |
|---|---|---|---|---|
| HVAC | Cool blue gradient, comfort/AC airflow | "AC & Heating in <City>" / "24/7 AC & Heat" | Call for Service | CAC / CMC |
| Roofing | Roofline + sky, storm-ready tone | "Licensed Roofing in <City>" | Schedule Inspection | CCC |
| Concrete | Warm gray, slab/texture, heavy/solid | "Concrete & Flatwork in <City>" | Get a Quote | (CBC/CGC) |
| Fence | Outdoor green, fence-line horizon | "Fence Installation in <City>" | Get a Quote | (specialty/registration) |
| Tree Service | Deep green canopy, arborist tone | "Tree Service in <City>" | Call for Estimate | (specialty/ISA if found) |
| Electrical (batch overflow) | Dark electric-blue, bolt motif | "Licensed <City> Electrician" | Call Now | EC / ER |
### Teaser pass/fail gate (every asset)
[ ] Company recognizable immediately  [ ] Hero compelling  [ ] CTA obvious  [ ] License/trust visible  [ ] Curiosity preserved (cut above the fold)
